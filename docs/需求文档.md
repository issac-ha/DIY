# 需求文档

版本：v1.0  
最后更新：2026-11-18  
项目：AI 硬件价格分析 Agent

## 1. 背景

硬件价格每天都在变，用户要在京东、淘宝、拼多多、抖音、闲鱼五个渠道间来回比价，既费时又容易看漏。

电商网页反爬严格，爬虫维护成本高、稳定性差。选定 B 站 UP 主「芝士华莱士」（mid 22697887）的每日硬件日报视频作为数据源：内容固定、每天更新、表格结构稳定，适合做多模态抽取。

## 2. 目标

### 业务目标

- 每天自动获得显卡、CPU、内存、硬盘、二手显卡的价格快照
- 支持按型号查各平台价格，并给出最低价与平台
- 支持按时间维度看价格走势
- 用对话方式回答问题，不需要用户理解数据库结构

### 项目目标（求职向）

- 完整覆盖多模态抽取、规则清洗、结构化存储、Agent 工具调用、接口与前端
- 关键决策有数据支撑，可复现、可回归
- 出问题能定位到具体环节，而不是"模型有时候不准"

## 3. 用户与场景

| 用户 | 场景 | 期望 |
|---|---|---|
| 装机用户 | 想买某张显卡 | 知道各平台今天多少钱、哪家最便宜 |
| 二手买家 | 想判断二手是否划算 | 看到二手成交价与全新价的差距 |
| 内容作者 | 想引用历史价格 | 拉出某型号最近 30 天走势 |
| 求职面试官 | 评估项目深度 | 看到清晰的数据链路与工程取舍 |

## 4. 范围

### 做

- 从指定 UP 主的日报视频抽帧识图
- 抽取显卡、CPU、内存、硬盘、闲鱼二手五类价格
- 清洗、校验、按日入库
- 提供查询接口、Agent 工具、对话界面、趋势图
- 输出每期采集报告

### 不做

- 全站电商爬虫
- 实时价格推送（当前按天）
- 用户账号、收藏、下单
- 主板、电源、机箱等其他品类
- 天梯图、跑分榜、股票行情表

## 5. 功能需求

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-01 | 获取 UP 主视频列表 | P0 | 能按发布时间倒序列出视频，标题含「显卡日报」的才进入处理 |
| FR-02 | 按固定间隔抽帧 | P0 | 默认 3 秒一帧，2 分钟视频抽出约 40 帧 |
| FR-03 | 相邻帧去重 | P0 | 同一张表停留期间只保留一帧，去重后帧数明显小于原始帧数 |
| FR-04 | 视觉模型读表 | P0 | 显卡表输出 16 行，每行含型号与四个平台价格 |
| FR-05 | 结构化抽取 | P0 | 输出 `{name, category, platform, price, change}`，型号必须来自基准目录 |
| FR-06 | 品类支持 | P0 | 支持 gpu / cpu / memory / ssd 四类，品类可自动推断 |
| FR-07 | 成色区分 | P0 | 闲鱼价标为 used，其余为 new，比价时互不干扰 |
| FR-08 | 涨跌幅采集 | P1 | 照抄视频表格里的当日涨跌额，不自行计算 |
| FR-09 | 异常过滤 | P0 | 相对基准价明显偏离的条目被拦截并记录 |
| FR-10 | 幂等入库 | P0 | 同一期视频重跑不产生重复产品、不重复写当天价格 |
| FR-11 | 日期准确 | P0 | 价格日期等于视频发布日期，补跑往期不覆盖当前价 |
| FR-12 | 查询接口 | P1 | 可按型号返回各平台最新价、最低价与平台 |
| FR-13 | 趋势接口 | P1 | 可按型号返回指定天数序列 |
| FR-14 | 对话查询 | P1 | 用户用自然语言问价格，Agent 调用工具后回答 |
| FR-15 | 采集报告 | P2 | 每期生成 Markdown 报告，含识图原文与入库结果 |
| FR-16 | 批量采集 | P1 | 支持连续处理多期，跳过无数据日期 |

## 6. 数据需求

### 品类

| 品类 | 数量（基准） | 关键指标 |
|---|---|---|
| 显卡 gpu | 16 全新 + 39 二手 | TSE 跑分 |
| CPU | 16 | R23 跑分 |
| 内存 memory | 6 | 每 GB 价格 |
| 硬盘 ssd | 4 | 每 GB 价格 |

### 平台

`jd` 京东、`taobao` 淘宝/天猫、`pdd` 拼多多、`douyin` 抖音、`xianyu` 闲鱼。

### 字段

- 型号名：严格使用基准目录写法，不允许模型改写
- 价格：正数，单位元；无货或看不清不入库
- 涨跌幅：视频表格原值，单位元，向下为负
- 日期：精确到天，取视频发布日期
- 成色：new / used

### 数据源约束

- 基准价当前使用 2025-11-17 行情，需替换为 2026-01-01 实际价格
- 视频不一定每期都有闲鱼表，缺失属正常情况

## 7. 非功能需求

| 维度 | 要求 |
|---|---|
| 成本 | 单期视觉调用约 10-15 次，费用在 0.1 元以内 |
| 幂等 | 重复跑同一期不产生重复数据 |
| 可追溯 | 每条价格能回溯到视频与帧；报告保留识图原文 |
| 可测试 | 视觉、抽取、入库可独立测试，不必每次下载视频 |
| 可观测 | 日志包含抽取条数、跳过原因、异常告警 |
| 可维护 | 型号目录集中在一个 JSON，新增品类不改表结构 |

## 8. 验收清单

一期视频跑完，检查以下各项：

1. 抽帧日志显示原始帧数与去重后帧数
2. 抽取条数在 180-200 之间
3. 日志中「型号不在目录中」为 0
4. 日志中「同型号重复」为 0
5. 报告里显卡表为 01-16，每行四个平台齐全
6. `RTX 5050` 与 `RTX 5060` 四平台价格各自正确
7. CPU 16 个型号均有记录（个别无货可缺失）
8. 数据库日期等于视频发布日期
9. 重跑同一期，产品数量不增加

## 10. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 视觉模型漏行或串行 | 价格错位 | 一行一型号 + 行号 + 严格目录匹配 |
| 视频版式变化 | 抽取失败 | 提示词与基准目录集中维护，报告留存原文便于比对 |
| UP 主停更或改版 | 数据中断 | 数据源可替换，入库层不依赖具体来源 |
| 基准价过旧 | 异常检测误报 | 定期更新基准目录 |
| 单期样本不足 | 结论不稳 | 批量跑 10 期后再调阈值 |
